# Shell 命令经验

## Windows 常用命令对照
列目录用 `dir`，查看文件用 `type 文件名`，删除文件用 `del`，删除目录用 `rmdir /s /q`。
查找文本用 `findstr "关键词" 文件名`，多条命令用 `&&` 连接。
路径分隔符用反斜杠，含空格的路径要加双引号。

## Linux 常用命令
列目录 `ls -la`，查看文件 `cat`，查找文本 `grep -rn "关键词" .`。
部署在 Render 等云平台时是 Linux 环境，命令要用 POSIX 写法。

## 长时间运行的命令
启动 Web 服务、监听类命令不会自己退出，会导致 run_command 超时。
需要验证服务时，改为运行一次性的测试脚本，或用 timeout 参数限制等待时间。
